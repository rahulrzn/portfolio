# Rahul Reji R. portfolio

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User specified React 19, TypeScript, Vite, Tailwind CSS v4, Motion, React Router, Lucide, React Hook Form, Zod, Vitest, Testing Library and Playwright. Cloudflare Pages deployment; frontend only.

## Users

Recruiters and collaborators assessing Rahul's engineering projects, technical skills and education; Rahul maintaining the content locally.

## Product Purpose

Present actual engineering work through an original, premium personal portfolio. Make projects easy to explore and content safe to maintain.

## Capabilities and Constraints

Public home, separate About and Skills pages, projects, project details, research and contact. Separate admin routes with profile, project, skills, research and settings editors. Browser-local drafts and explicit publication, shared-component preview, validated backup/import, recovery and reset. No backend, API, database, real authentication, fabricated links or personal claims. Original reference PDFs must never ship in public assets.

An editable Open to Opportunities section presents user-provided entry-level role interests, Bangalore/Kerala/Chennai priority, full-time/graduate/remote availability and flexibility across suitable technical domains. The Profile editor manages its content/visibility and optional contact details, including safe telephone links. Missing fields in older snapshots/backups receive compatible defaults.

## Brand Commitments

Rahul Reji R.; dark default with a coordinated light palette; oversized mixed-color Bebas Neue name masthead, Space Grotesk headings and legible Source Sans 3 body copy. Use the supplied LinkedIn portrait and matching RR monogram. Keep project showcases compact, factual and easy for recruiters to scan. About, Skills, Projects, Research and Contact have distinct compositions. The user explicitly removed workflow diagrams and abstract 3D models. Accessible and usable with motion disabled. Current design authority: DESIGN.md.

## Product Principles

- Truth before spectacle.
- Content edits cannot modify application structure.
- Drafts never change published content until confirmation.
- Storage failures preserve evidence and recover valid content.
- Local publication is clearly described as browser-local.

## Accessibility & Inclusion

Keyboard navigation, semantic structure, labeled forms, focus-managed dialogs, reduced motion, contrast, mobile public and admin interfaces, no horizontal overflow.
