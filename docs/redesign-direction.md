# Final portfolio direction

The user rejected the original split hero, workflow diagrams, insufficient structural redesigns, oversized project cards and abstract 3D models. The final direction spends expressive typography on the identity and prioritizes factual, digestible project evidence elsewhere.

Dark default and a distinct light palette share a mixed-color condensed name masthead, central actual portrait, clear graduate/technical introduction and prominent résumé action. Source Sans 3 replaces thin small body text; Space Grotesk provides clear headlines. A large sticky header uses the RR monogram and exactly one animated active navigation state. The homepage section state follows cold-loaded content and scrolling.

Projects are compact text-first showcases with no decorative media. Context, stack and case-study/demo/repository links are visible; uploaded images remain supported. Dedicated About and Skills pages join Projects, Research and Contact, each with a distinct layout. Full verified facts remain available in public pages and the résumé, with admin controls unchanged apart from requested contact fields.

Motion supports navigation, page introductions, the portrait, theme switching, mobile menus and project filtering. Native skills disclosures animate when supported. Reduced motion and touch interaction remain first-class. No Three.js payload remains.

The user delegated creative decisions and authorized necessary downloads. The new font packages were checked against registry versions, OFL licenses and package contents before installation; visitors load them locally. Cloudflare Pages remains the deployment target.
