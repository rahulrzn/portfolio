Using the Anatomy skill at Figure scale: lightweight, interactive isometric technical figures. A data-processing appliance uses removable cartridges to represent workflow stages. Selecting a stage lights its cartridge and explains the actual project operation. This is an original conceptual illustration, not a screenshot or a literal claim about hardware.

Parts: bench, four feet, two chassis rails, intake panel, output panel, three/four cartridge enclosures, four thin data plates per cartridge, two mount screws per cartridge, three ventilation slots per cartridge, one status lamp per cartridge, four bench fastening plates, four corner fasteners, and each cartridge's front connector. Over 40 purposeful elements per figure. Four tones give the base, side, front and top real volume. Parallel modules sit on their rails and are drawn back to front. No WebGL, pipes, shaders or continuous animation required.
