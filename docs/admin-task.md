## Interfaces and routing
- Export default `src/admin/AdminApp.tsx`, mounted at top-level `/admin/*` with React.lazy. Use nested React Router Routes. `/admin` -> `/admin/login` or dashboard; `/admin/login`, `/admin/dashboard`, `/admin/profile`, `/admin/projects`, `/admin/skills`, `/admin/research`, `/admin/settings`.
- `useWorkspace()` returns `{repository,snapshot}`. `snapshot.draft`, `.published`, `.warning`, `.activity`, `.revision`; synchronous saveDraft/content validation before every save. Public provider always uses published data.
- `imageStore.put(file)` validates format, <=3MB, dimensions 64–5000 px <=16MP then stores a blob in IndexedDB, returning `image:uuid`. `imageStore.get/remove`. Never delete a blob still referenced by published content. Removing an image reference need not garbage collect blob immediately.
- `exportBackup(repository)` and `importBackup(raw,repository)` portable image-containing backups, plain content exports also accepted. `downloadFile` helper. Imports stage draft, public unchanged.
- Shared `ContentImage` from `src/components/ContentImage.tsx` accepts reference, alt, className, fallback. `ExternalLink` safe HTTP(S).
- Root will create `src/public/PublicRoutes.tsx` default export, supporting index, projects, projects/:slug, research, contact. Render it in `/admin/preview/*` inside `<ContentProvider draft base="/admin/preview">`; preview uses the SAME public components. Add a preview banner linking back to dashboard. No approximation or iframe. It will exist shortly; do not block on missing source.
- Root's base CSS tokens: `--bg:#0b1220`, `--surface:#0f1929`, `--elevated:#172338`, `--text:#e2e8f0`, `--muted:#a3b1c6`, `--accent:#5eead4`, `--border:rgba(226,232,240,.12)`, font Manrope. Shared classes `.button`, `.button.secondary`, `.button.small`, `.text-link`, `.muted`. Import own `admin.css` with prefixed classes to avoid overriding public layout. Fields/buttons may define scoped `.admin-*` styles. Separate task-oriented lighter navy admin shell, crisp hierarchy, mobile sidebar/menu and flexible forms.

## Required behavior
- Login professional password UI, show/hide, required minimum-length validation. Any user-entered 8+ character session phrase opens IN-MEMORY development session; no hardcoded password, no localStorage auth, no secure claims. Prominent "Local development workspace" and "This gate is not authentication. Any 8-character phrase opens this browser-local editor." Sign out closes in-memory session. Reload may require gate again; edits persist.
- Dashboard actual draft/published project counts and activity, quick actions. Persistent browser-local publication notice.
- Global save/revert/publish: local form unsaved text distinct from saved draft; page-level Save draft, Cancel/Revert to saved. Preview saved drafts before publish; Publish confirmation dialog with explicit public/local-only explanation. Global discard draft -> repository.revert confirmation. Restore defaults -> repository.resetDraft confirmation, then explicit publish required. No auto publication. Protect unsaved forms on route navigation/reload (native confirmation acceptable), and offer clear discard/cancel.
- Profile edit all schema profile fields including education, actual image upload/change/remove. Name, headline, introduction, about, location, email, GitHub/LinkedIn, resume reference in settings. RHF + Zod validation; understandable field messages.
- Projects full CRUD: add, edit, duplicate stable new ID/new unique slug, delete confirmation, order up/down or numeric order, featured, draft/published status, all text fields (overview/problem/approach/implementation), category/year/context, technology add/remove, external GitHub/live/caseStudy URL, image upload/preview/removal, workflow and outcomes editing. Real Live Demo changes reflected in shared public preview and after global Publish. Draft items hidden public.
- Skills add/edit/remove/reorder categories and individual skills with stable IDs; destructive removal confirmation.
- Research add/edit/remove (confirmation), details, date/publication/link/technology, status, order, outcomes.
- Settings seoTitle/description, siteUrl, resumeUrl, contactHeading/intro, footerNote; backup export/import with file validation, size limits, invalid import error leaving public data intact, damaged raw data export if warning; reset draft defaults confirmation.
- Dialogs native `<dialog>` with showModal, focus restoration, cancel/Escape, action buttons; Motion subtle dialog/menu/notice entrances and toast/status changes; prefers-reduced-motion. Validation safe text only. Responsive 390px, keyboard/focus labels, h1 per route, errors role=alert and success role=status.
- Mark ALL admin routes noindex, including preview/login.
