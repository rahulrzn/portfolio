## Resolved finding

**P2 — Formatted meta tags retained generic descriptions.** The original generator required literal `<meta name=` / `<meta property=` prefixes. Prettier's line breaks prevented description and Open Graph description replacement, while title replacement still worked. The actual generated Soho Suite route retained the generic homepage descriptions.

The generator now locates metadata independently of whitespace, line breaks, attribute order, or quote style; requires each expected template tag to exist; and uses replacement callbacks to preserve literal content. It writes the validated settings description on ordinary routes and each project's description on that project's route. Titles and Open Graph values use the same content. Existing text escaping remains in place.

The verifier now parses the actual **static** head with DOMParser before application JavaScript can repair it. It compares decoded values exactly, rather than searching the HTML for a project name. It checks all public/default project routes and the eight generated admin routes, including single indexing directives and absence of inappropriate canonical or structured-data tags.
